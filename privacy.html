개인정보 처리방침

시행일: 2026년 10월 23일

taBtaP(아이폰 앱과 맥 에이전트)는 개인정보를 수집하지 않습니다. 개발자가 운영하는 서버가 없고, 사용 기록이나 분석 정보, 광고 식별자를 어디에도 보내지 않습니다.

1. 통신

아이폰 앱과 맥 에이전트는 같은 로컬 네트워크 안에서 서로 직접 연결합니다. 연결은 페어링할 때 만든 키로 암호화됩니다. 아이폰은 누른 버튼의 번호와 슬라이더 값만 보내고, 맥은 버튼 구성과 실행 결과를 돌려줍니다. 이 정보는 두 기기 밖으로 나가지 않습니다.

2. 기기에 저장되는 정보

  • 맥: 버튼 구성, 연결한 아이폰 목록(기기 이름과 페어링 키), 에이전트 설정. ~/Library/Application Support/TabTap 폴더에 저장됩니다.
  • 아이폰: 연결한 맥의 정보와 페어링 키(키체인), 맥에서 받은 버튼 구성, 화면 모드 설정.

이 정보는 각 기기에만 있으며, 앱을 삭제하거나 맥에서 위 폴더를 지우면 함께 삭제됩니다. 맥 메뉴에서 연결한 아이폰을 해제할 수도 있습니다.

3. 권한

  • 로컬 네트워크(아이폰, 맥): 같은 와이파이에 있는 맥을 찾고 연결하는 데만 씁니다.
  • 카메라(아이폰): 맥 화면의 연결용 QR 코드를 읽는 데만 씁니다. 사진이나 영상을 저장하거나 보내지 않습니다.
  • 손쉬운 사용(맥): 창 목록을 읽고 창을 바꾸며, 버튼에 지정한 키 입력을 실행하는 데만 씁니다. 화면 내용이나 입력한 글자를 기록하지 않습니다.

4. 제3자 제공

수집하는 개인정보가 없으므로 제3자에게 제공하거나 처리를 위탁하지 않습니다. 앱에는 외부 분석 도구나 광고 도구가 포함돼 있지 않습니다.
